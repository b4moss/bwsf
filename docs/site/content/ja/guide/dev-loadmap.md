# バージョニングについて

`bwsf` はセマンティック・バージョニングを採用しています。

現在、v1.0.0 のリリースは未定です。

v0.x.0 のアップデートは、常に破壊的変更が考えられます。

プロダクションでの利用は、十分ご注意ください。
