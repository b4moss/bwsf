# 製品仕様（決定事項）

実装前に固めた **製品・設定・CLI の決定事項** を置く場所です。

| 置き場 | 役割 |
|--------|------|
| **`docs/specs/`（ここ）** | バージョン単位の仕様正本（決定のみ） |
| [`docs/tests/`](../tests/README.md) | テスト仕様書（TDD 用。実装前の Red 契約） |
| [`docs/site/`](../site/) | ユーザー向けガイド（公開サイト） |

仕様とテストは分けて管理する。テスト仕様は本ディレクトリを参照して書いてよいが、決定の再解釈はここに戻す。
