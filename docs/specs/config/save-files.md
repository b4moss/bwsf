# save_files（ファイル選択）

現行の管理対象ファイル選択（グローバル／プロジェクト）の仕様正本。  
テスト仕様: [`../../tests/config/save_files_bang.md`](../../tests/config/save_files_bang.md)。

関連 Issue: [#177](https://github.com/b4moss/bwsf/issues/177)

## ルール

| 項目 | 決定 |
|------|------|
| キー | **`save_files` のみ** |
| `not_save_files` | **廃止**（グローバル／プロジェクトとも。存在したらスキーマエラー） |
| 未設定／空配列（適用後のパターンが空） | 基盤ルールのみ（管理対象をそのまま） |
| プロジェクトとの関係 | プロジェクトの `save_files` が **1 件以上**あるとき、その内容で**完全オーバーライド**（グローバルとマージしない）。空配列／未設定ならグローバルへフォールスルー |

## 解釈

基盤ルール（管理対象検出）通過後に、basename へ glob を適用する。基盤外ファイルは取り込まない。

| エントリ | 意味 |
|----------|------|
| 通常の glob（例: `.env*`） | 含める（肯定） |
| `!` で始まる glob（例: `!.env.local`） | 除外（否定）。`!` の直後がマッチパターン |

適用順:

1. 肯定パターンが1つ以上ある → それらに一致するものだけを候補にする
2. 肯定パターンが無い → 基盤通過分すべてを候補にする
3. 否定パターン（`!…`）を候補から除外する

例（「`.env*` のうち `.env.local` 以外」）:

```jsonc
"save_files": [".env*", "!.env.local"]
```

例（基盤対象から特定だけ除外。肯定なし）:

```jsonc
"save_files": ["!.env.local", "!*.auto.tfvars"]
```

v0.18 のプロジェクト設定にあった `not_save_files` は廃止。残っている場合はスキーマエラー（手動で `save_files` + `!` へ書き換える）。
